# 🎓 ВШКНиИИ Филворд-бот — Викторина для дня открытых дверей

Этот бот для **ВКонтакте** создан специально для дня открытых дверей в Высшей школе компьютерных наук и  искусственного интеллекта БФУ им. И. Канта.

Бот предлагает пройти викторину в формате **филворда** — сетки с буквами, где спрятаны 12 слов. Участники ищут слова и отправляют их боту, а он отслеживает прогресс, подбадривает и вручает награду за полное прохождение.

---

## ✨ Особенности

- 🔍 **Филворд** — интерактивный поиск слов по картинке
- 📊 **Статистика для админа** — команда `/stats` показывает количество участников и победителей
- 💬 **Дружелюбные фразы** — разные варианты реакции на правильные и неправильные ответы
- 🎉 **Поздравление с призом** — после прохождения отправляется итоговое сообщение
- 💾 **SQLite** — сохраняет прогресс каждого пользователя

---

## 🚀 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/start`, `начать`, `Начать` | Показать кнопку для запуска викторины |
| `/stats` | (только админ) Показать статистику |

## 🛠️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/NevatusNikita/VK_quiz_bot.git
cd VK_quiz_bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` и добавьте токен вашего сообщества ВКонтакте:

```env
BOT_TOKEN=ваш_токен_сообщества
```

### 4. Настройка `config.py`

```python
ADMIN_ID = 123456789               # Ваш ID ВКонтакте
QUIZ_IMAGE = "photo-123456_789012" # ID картинки с филвордом
REQUIRED_WORDS = 12                # Количество слов
CORRECT_WORDS = [...]              # Список правильных слов
```

### 5. Запуск бота

```bash
python main.py
```

После запуска в консоли появится сообщение: `BOT STARTED`

## 🤖 Как бот работает

1. Пользователь пишет `Начать` или нажимает кнопку
2. Бот отправляет картинку с филвордом и правила
3. Пользователь ищет слова и отправляет их в чат
4. Бот проверяет слово:
   - ✅ Правильное и новое → прогресс +1, подбадривающая фраза
   - ❌ Неправильное → мягкая подсказка
   - 🔁 Уже найдено → напоминание
5. После 12 слов → поздравление и сообщение для организатора
